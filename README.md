# دستیار مقایسه قیمت

افزونه کمکی برای مقایسه قیمت و اطلاعات محصولات ووکامرس با منابع فروشگاهی دیگر.

## ویژگی‌ها
- جستجوی محصول با نام یا SKU
- ثبت لینک منابع مختلف
- مقایسه قیمت
- پیشنهاد کاهش/افزایش قیمت
- دکمه اعمال قیمت پیشنهادی
- بررسی عنوان، توضیحات، توضیح کوتاه، تگ و اطلاعات سئو
- امکان ویرایش دستی قبل از اعمال
- رابط فارسی و مینیمال
