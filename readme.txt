== Description ==
Price Compare Assistant provides a Persian-first foundation for matching WooCommerce products with external marketplace listings and reviewing suggested price/content changes.

== Installation ==
1. Upload the price-compare-assistant folder to /wp-content/plugins/
2. Activate the plugin.
3. Open WooCommerce > مقایسه قیمت.
